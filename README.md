# PowerShell-M365-Starters

A curated toolkit of production-ready PowerShell scripts for **Microsoft 365** and **Microsoft Teams** administration. This repository focuses on enterprise voice provisioning, tenant governance, and telephony diagnostics using the modern `Microsoft.Graph` SDK and `MicrosoftTeams` PowerShell module.
